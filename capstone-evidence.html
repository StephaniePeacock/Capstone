4. Three Findings and Repairs

Finding and condition Impact Repair Exact retest and result
Navigation tabs displayed incorrectly when viewing in wide format after initial changes. After correcting the narrow view styling, wide-view navigation was extending past the width of the page, and was showing as a very large block, pushing the rest of the page down. nav-list, nav-list a I added width: auto to the .nav-list media query. Both wide and narrow view nav lists now display as intended.
Table regions were displaying double borders when focused. about.html - .table-region, th I added :not(th) to the :focus-visible selector. My specificity couldn't target .table-region with this same tactic, so I overrode it with a specific .table-region:focus-visible selector and the value outline:none Tabbing focus to within the table now only shows one border as intended.
Nav-list was layered below the main content at narrow widths nav-list I removed the z-index property from the .site-header - it's value of 0 was causing the entire header to lay below the main content. Nav-list now correctly layers above the main content at all widths.
Nav-list animation was playing at wide width. nav-list I added a media query within the reduced motion media query that limits the animation to narrow widths. Nav-list no longer shows animation at wide widths.
Failed HTML check - help.html duplicate id="result" I removed the id from the results, as the tag was not being used for styling. HTML validation now passes for help.html.
